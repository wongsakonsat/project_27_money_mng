# Response Formatting Rules

- **DO NOT USE LaTeX SYNTAX**: Never use `$`, `$$`, `\text{...}`, `\rightarrow`, `\mathbf{...}`, or any LaTeX math blocks in responses. The IDE chat window does not render LaTeX, resulting in unreadable `$\` raw characters for the user.
- **Use Plain Markdown Math**: Format calculations in clean plain text and standard markdown, e.g., `ยอดคงเหลือ = 10,000 - 2,000 = 8,000 บาท`.
- **Use Unicode Arrows**: Use `->` or `➡️` instead of `\rightarrow`.
- **Use Standard Bold**: Use `**ข้อความ**` for bold text instead of `\mathbf{...}`.
